# Mineradio

![Mineradio 暗场启动页](./docs/assets/readme/cinema-beat-smoke.png)

Mineradio 是一款 Windows 桌面沉浸式音乐播放器，把搜索播放、歌词舞台、粒子视觉、3D 歌单架和完整桌面模式组合成一个更接近现场感的私人音乐空间。

## 立即下载 Windows 安装包

> 本仓库是 Mineradio 的**非官方 fork 构建**，与原作者的发布渠道无关。安装包发布在本仓库的 Releases；上游项目见 [XxHuberrr/Mineradio](https://github.com/XxHuberrr/Mineradio)。

| 下载入口 | 说明 | 链接 |
| --- | --- | --- |
| GitHub Releases（本仓库） | 安装包、版本说明与随附源码 | [查看 Releases](https://github.com/2128cz/Mineradio/releases) |
| 本仓库源码 | 与安装包同版本的完整源码（GPL-3.0 要求随二进制提供） | [2128cz/Mineradio](https://github.com/2128cz/Mineradio) |

安装时只需要下载并运行 `Mineradio-2.2.0-Setup.exe`。同一 Release 还应包含 `.blockmap`、`latest.yml` 与源码压缩包，这些是更新与合规所需的附带文件；不要把 `.blockmap`、`latest.yml` 或 `win-unpacked` 目录当成正式安装包。

本 fork 在上游 2.2.0 的基础上加入：歌词 PV 模式（视觉预设 13，含 21:9 / 16:9 / 4:3 / 1:1 / 4:5 / 3:4 / 9:16 画幅跟随、超宽屏模糊铺边、分镜预热）、**环形数据流**（视觉预设 14，见下文）、**动画绘制档位**（自动 / 效果 / 性能，对预设 13 与 14 同时生效）、视觉控制台里的 PV 参数组（含“重新生成当前歌”）、以及一组窗口与后台行为修复。完整差异见提交历史。

## 下载或安装被拦截怎么办

小众 Electron 桌面软件、未签名安装包有时会被浏览器、Windows Defender 或 SmartScreen 提示风险。请先确认安装包来自本仓库的 Releases 页面，文件名是 `Mineradio-2.2.0-Setup.exe`。

1. 浏览器下载栏提示风险时，打开下载列表，点这条下载右侧的 `...` 三个点，选择 `保留` / `仍要保留` / `显示更多` 后继续保留。
2. Windows SmartScreen 弹出蓝色拦截窗口时，点 `更多信息`，再点 `仍要运行`。
3. 如果杀毒软件明确显示木马、高危或已经隔离，不要强行运行；删除该文件后重新从本仓库 Releases 下载，仍然异常请带截图提交到本仓库 Issues。

## 核心特性

- 首页包含每日推荐、平台推荐、继续听、听歌画像和我的歌单入口
- 完整桌面模式保留播放器、主页、歌单和桌面交互
- 支持本地 MP4 与 Wallpaper Engine 视觉内容
- 播放后切换到 Emily / 默认播放态视觉，歌词舞台与粒子舞台同步工作
- 基于节奏的电影镜头视觉系统
- 面向长播客和 DJ 曲目的专属视觉模式
- 歌词舞台、自定义歌词、歌词位置与视觉控制
- 自定义专辑封面上传与裁剪
- 右键唤起 3D 歌单架，支持歌单队列浏览
- 网易云音乐账号、搜索、歌单、播客等体验接入
- QQ 音乐搜索、登录态与音源补充接入
- GitHub Releases 更新检测与下载入口
- 首次启动内置「默认测试」视觉用户存档，软件内默认视觉参数与该存档一致
- 歌词 PV 模式：把当前歌曲的歌词编译成分镜档案，播放时在背景层实时绘制（视觉预设 13）
- 环形数据流：一圈随歌词转动的数据环，外圈分几种元素（细光线、实心柱状条、柱状拼成的扇形）各自跟随频谱，歌词贴着环排、鼓点决定环的缩放与抖动（视觉预设 14）
- 动画绘制档位：自动 / 效果 / 性能三档，性能档以更低成本绘制同一幅画面

## 歌词 PV 模式

视觉控制台里选择 **歌词PV**，播放一首有歌词的歌，背景就会变成按歌词排布的「文字分镜」：每一句词都有对应的镜头、版式与出入场，随播放进度推进。切回任何其他预设即刻恢复原来的视觉，桌面歌词不受影响（它有自己的通路，不归这个模式管）。

![歌词 PV 模式](./docs/assets/readme/pvmode.png)

几点说明：

- **先有档案才画**：播放到某首歌时，它的分镜档案会提前算好并落到本地缓存（播放列表里后几首在播放期间会顺带准备好），播放时只读档案出帧，所以切歌不会卡。
- **引擎体积**：第一次选中该预设时才加载 PV 引擎（约 2MB，本地文件、不需要联网），不选它就不会加载。
- **内存**：离开该预设时会释放出帧用的绘制器与画布。
- 无歌词或只有占位歌词的曲目不会生成档案，背景下保持原样。
- **画幅跟窗口形状走**：规划时按当前视口在引擎支持的画幅里取最接近的一档（21:9 / 16:9 / 4:3 / 1:1 / 4:5 / 3:4 / 9:16），播放时画面按等比放大铺满窗口、多出的部分由画面边缘自然裁掉（单边最多约 6.7%），所以不会留下黑边。窗口比例跨档后下一首歌会按新画幅重新规划一次（档案键含画幅，旧档自动不命中）；当前正在播的这首歌若与新形状差得超过 15%，会退回等比完整显示并留对称黑边。
- PV 引擎移植自开源项目 [JIZURA](https://github.com/852wa/JIZURA)（作者 hakoniwa，MIT 授权），其许可证原文随包附在 `vendor/jizura/LICENSE.txt`；移植范围与相对上游的唯一差异见 `docs/THIRD_PARTY_PORTS.md` 与 `NOTICE.md`。

## 环形数据流

视觉控制台里选择 **环形数据流**，背景会变成一圈缓慢转动的数据环：环带、环形面板、外圈光束、流线和辉光都跟着歌走，当前这句词停在右侧的读词位置上。

- **歌词**：默认是沿半径向外排的列表，正在唱的那句比周围行大一号（周围行为它的 0.72 倍），并按它与读词位的距离连续过渡，所以转环时是“长大着进来”而不是跳变。颜色跟随视觉设置里的歌词配色；进出场沿用控制台「歌词动画」的样式（漂浮 / 柔滑 / 玻璃 / 线光 / 故障），「上下句清晰」「上下句间距」「边缘渐隐」同时生效。
- **整圈铺满**：列表读完一圈回到原处，每句在读词位置的正对面（默认 9 点方向）生成，绕过一圈后在同一个位置消失——转环时不会从屏幕侧面突然冒出来。
- **径向模式**：把「侧边轴向歌词」关掉，就变成一句一环的径向歌词。侧视时贴着环内缘直排；相机看向圆环上方 / 下方时换成圆弧；能看到整个圆环时放到环外并放大。
- **节拍**：环的缩放踩歌曲的统一节拍，检测到的鼓点只用来给“有鼓的那一拍”加重。顶环踩的是分析给出的**节拍点**，不是它铺在歌曲上的整张节拍网格：网格里被判定“这一位不是鼓”的弱位以前也顶一下环，120 BPM 因此读成每秒四下的抖动，现在只剩每秒两下的拍点。环还有一道 0.24 秒的最小间隔：靠得比这更近的拍只留更强的那一次，因为一回顶环本身就要四分之一秒才长开，再密就糊成一团；歌本身够快时（0.25 秒一拍）不会被削；没有节拍地图、退回实时鼓点检测时也是同一道间隔。一拍的大小属于**这一拍本身**（地图对该拍的判断，叠上它底下真实听到的鼓），轻重拍的差距拉开到接近两倍；实时底鼓包络一度可以把它顶得更大，但包络在有声音的段落里几乎不归零，于是每一拍都被顶到旋钮的最大值，环就成了涂在音量上的画面。顶出的是**环自己**——网格、流线、光束这些背景不跟着一起缩放，所以这一顶是相对画面长大的，而不是整幅画面等比放大 2%（那种缩放肉眼读不出来）。电平那一道闸只回答“现在有没有声音”：静音段落环完全不动，但只要听得到声，节拍的幅度就保留大半，不再按音量线性缩水。抖动也是鼓点给的冲量——击中的那一帧按鼓点的方向甩出去、随包络滑回，不再是与鼓点无关的正弦抖动。转环快慢仍按歌曲 BPM；外圈光线每一簇读取自己那一格频谱，鼓点到来时整圈伸长再自行回落。光线自己那套缓慢的攻防与呼吸不再固定：「光线频谱跟随」拧到底，光束就是一帧一帧的频谱，只剩声音给的起伏。
- **外圈元素**：三种族共用同一套频谱长度，但各有各的动作——**细光线**（成簇、边缘收锥形、带流动的虚线拖尾，慢起慢落、留一点呼吸）、**实心柱状条**（同一簇里每条一样长，从环缘画到尖端，没有拖尾，一两帧到位、回落快）、**柱状拼成的扇形**（条宽按这一簇的角度间隔算出来，相邻的条并成一整块扇形，画在环的远侧、被细光线压在上面，动得最少、也保留最多的底长）。同一拍对三者的抬升量不同，每个光簇还有自己的频谱增益，所以相邻的光簇不会一起长。亮度上也分主次：细光线是画面主体，柱状条与扇形只保留不到四分之一的光线亮度、不带色、外面裹一层淡雾，作为光线下面的灰底色——柱状条又宽又实心、每一笔都满强度，给到光线的亮度就会反过来变成一整片白墙。它们的高度也完全属于频谱：没有声音就降到零，节拍的那一抬同样乘在这一格电平上，所以安静段落里不会剩下一圈立着的柱子。绘制顺序按“元素族 + 远近分组”走，不再按建层的先后，所以加一层不会悄悄改变谁盖住谁。
- **视角**：拖拽平移、滚轮缩放；面板上的「重置视角」可以把视角一键复位。所有旋钮在「动效 → 环形数据流」里，独立于其他预设保存。

## 使用说明

Windows 用户从本仓库 Releases 下载安装包。

正式分发以 Release 里的 `Mineradio-2.2.0-Setup.exe` 为准，不建议直接使用 `win-unpacked` 目录。安装包会创建桌面快捷方式。

已经安装过旧版本的用户可直接运行新的安装包完成更新。软件内更新入口只会打开浏览器下载页，不会在客户端内下载或应用补丁。

## 开发运行

```bash
npm install
npm start
npm run build:win
```

桌面版入口由 Electron 主进程加载本地服务。`npm run build:win` 会生成 Windows NSIS 安装包，产物位于 `dist/`。

## 更新机制

Mineradio 会请求 GitHub Releases latest 检测新版本，本 fork 指向本仓库（`2128cz/Mineradio`）的 Releases。远端版本高于本地版本时，应用内更新入口会展示 Release 内容，并通过系统浏览器打开下载页；即使 Release 附带完整安装包，`2.0.3+` 客户端也不会读取、下载、缓存或应用该附件与补丁。

本地验证更新链路时，可以通过 `MINERADIO_UPDATE_MANIFEST` 指向一个本地 manifest JSON 或 HTTP 地址来模拟线上 Release。

## 第三方音乐平台说明

Mineradio 不是网易云音乐、QQ 音乐或腾讯音乐娱乐集团的官方客户端，也不隶属于任何音乐平台。

项目中的第三方平台接入仅用于个人学习、本地客户端体验和用户自有账号的播放辅助。请遵守对应平台的用户协议、版权规则和会员权益规则。项目不会提供绕过付费、绕过会员、破解音质或重新分发音乐内容的能力。
